## Overview

Welcome to the **Reyzzarjam** — a single repository that contains three independent projects built and maintained by Reyzzarjam. Each project serves a distinct purpose but shares the same design philosophy: clean, modern, fast, and built with a focus on user experience.

This repository is not just a code dump. It is a live showcase of how a personal platform, a documentation portal, and a game utility script can coexist within one ecosystem.

## Project 1 — Reyzzarjam Personal Platform

### About

A personal web platform that combines a portfolio, utility tools, mini-games, wiki, blog, and progress systems into one application. It is bilingual (Indonesian and English), supports theme switching, offers 26+ Google Fonts, and includes a full settings panel with appearance, performance, diagnostics, keybind, account, and information tabs.

Everything runs on the client side. User data is stored locally in the browser, with optional export and import through an encrypted `.rx` file. No user data is sent to any server except for visitor analytics used for the visitor counter.

### Highlights

- Bilingual interface (ID and EN)
- Multi-font support (26+ Google Fonts)
- Theme switching (dark and light, for Bio Pro mode)
- Two bio modes: Classic and Pro
- Achievement system with unlock tracking
- Battlepass with seasons, levels, borders, and banners
- Mailbox system with unread badge
- Story telling engine with chapters and parts
- 20+ utility tools and 7+ mini projects
- RC4 encrypted data export and import (`.rx` file)
- Full diagnostics panel (FPS, ping, jitter, packet loss, Web Vitals)
- Cookie consent banner
- Offline and online detection with toast notifications
- Automatic version checker with update toast

## Project 2 — ReyzzHub Docs

### About

ReyzzHub Docs is a static documentation web application built with React and Vite. It serves as the official documentation portal for the ReyzzHub UI Library, providing usage guides, execution instructions, changelog, and interactive demos.

The site uses React Router v6 with the data router API (`RouterProvider`), and a single root layout that wraps all pages with a global navbar and footer. It includes legal pages (Privacy Policy, Terms of Service), a maintenance page, and a built-in Word Search demo powered by Indonesian and Javanese dictionary datasets.

## Project 3 — ReyzzHub Universal

### About

ReyzzHub Universal is a Roblox script hub written in Lua, designed to work across most Roblox games. It combines a large feature set (combat, visuals, movement, teleport, world, camera) into a single, unified UI built with its own in-house UI library.

The script supports both desktop and mobile Roblox clients, includes a config manager for saving and loading settings, a keybind manager for custom hotkeys, multi-language UI (Indonesian and English), and multiple cloud endpoints for logging, blacklist checking, staff detection, and animation databases.

### Feature Categories

| Category | Features |
| --- | --- |
| Combat | Aimbot, Prediction, Wall Check, TriggerBot, Rapid Fire, Universal Gun, Hitbox Expander, Reach, Auto Clicker, Touch Fling, Sky Desync, Invisible Clone, TP Unanchored |
| Movement | Moonwalk, Infinite Jump, Noclip, Fly, Platform Walk, Swim Mode, Spider Wall, Bhop, Auto Regen, Freeze, Loop Speed, Fly Vehicle |
| Visuals | ESP Player, Inventory Display, Spectator List, Global Hide, Night Vision, X-Ray, Crosshair, Leaderboard, Proximity Warning |
| Camera | Freecam, Max Zoom, Perspective, FOV Lock, No Bobbing, No Recoil Camera |
| Teleport | Manual TP, Copy Position, CTRL + Click TP, Bookmarks, Server Hopper, Player Spectate, Auto Follow |
| World | Fullbright, No Fog, No Particles, Disable Lighting, Walk on Water, Gravity Control, FPS Boost, Anti-Void, BTools, GUI Inspector, RTX Graphics |
| Misc | God Mode Bug, Ghost Mode, Anti-Drown, Fake Lag, Auto Prompt, Animation Changer, Time Changer, FPS Cap, Chat Bypass, Chat Logger, Identity Spoofer, Anti Staff, Auto Reconnect, Anti-AFK |

### How To Use

**Step 1 — Get an executor.**
You need a Roblox script executor to run ReyzzHub Universal. Popular options include Synapse X, Fluxus, Solara, Wave, and similar. Use only trusted sources.

**Step 2 — Join the game.**
Open Roblox and join any game where you want to use the script.

**Step 3 — Paste the loader.**
Open your executor, paste the following into its script box:

```lua
loadstring(game:HttpGet("https://reyzzhub.netlify.app/universal/main.lua"))()
```

**Step 4 — Execute.**
Click Execute (or the equivalent button in your executor). Wait a few seconds for the UI to load.

**Step 5 — Open the menu.**
Once loaded, click the floating button on screen or press `K` / `Right Ctrl` to toggle the main panel.

**Step 6 — Configure.**
Use the sidebar to navigate between tabs. Toggle features on or off. All changes are applied live.

**Step 7 — Save your setup (optional).**
Go to the Settings tab, enter a config name, and click Save. To auto-load your config on next execution, click Set as Auto-Load.

**Notes:**
- Some features may not work in all games. This is a universal script — coverage is best-effort.
- If the menu does not appear, check your executor console (F9) for errors.
- On mobile, the script auto-detects touch devices and enables the Mobile tab.

### Config System

Settings are saved as `.json` files in the executor workspace folder `ReyzzHub_UniversalConfigs`.

Features:
- Save current state to a named config
- Load config from a list (dropdown + search)
- Set as Auto-Load (applied on next execution)
- Delete config
- Reset keybinds
- Diagnose missing UI listeners

### Security

- Anti-Discord Webhook: blocks outgoing requests to `discord.com/api/webhooks`
- Anti-Logger: blocks known loggers (grabify, psor.org, ip-logger)
- `hookmetamethod` on `__namecall` to intercept `HttpGet`
- `replaceclosure` to hook `request` / `http_request`
- Single-instance guard via secure flag in `getgenv()`
- Protected GUI names via random GUID
- HWID-based identification for logging

### Cloud Backend

| Endpoint | Purpose |
| --- | --- |
| `reyzzhub.netlify.app/universal/main.lua` | Main loader |
| `reyzzhub.netlify.app/.netlify/functions/log` | Discord webhook proxy |
| `reyzzhub.netlify.app/black/list.json` | Blacklist database |
| `reyzzhub.netlify.app/api/list-staff.json` | Staff/admin database |
| `reyzzhub.netlify.app/api/config.json` | Animation database |
| `reyzzhub.netlify.app/api/anti-afk.lua` | Anti-AFK injection |
| Google Apps Script | Google Sheets visitor logger |
| Discord Webhook | Execution logger |

### Executors

Tested and supported executor APIs:
- Synapse (`syn.request`, `syn.protect_gui`)
- Fluxus
- Solara
- Most modern executors providing `request`, `writefile`, `readfile`, `makefolder`, `listfiles`, `isfile`, `setfpscap`, `queue_on_teleport`, `hookmetamethod`, `replaceclosure`.

If an executor lacks file IO, config saving is disabled but all other features still work.
